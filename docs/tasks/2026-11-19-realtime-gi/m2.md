# M2：SSGI（Screen Space GI）

状态：完成（Deferred 光栅路径，严格 D3D11／native D3D12 已验证；独立 trace/composite + direct-color history + 时域/空域降噪）
提交：`1768b21`（首版）、`fa5667f`（自反馈/散点修复）

## 范围

`GlobalIlluminationMethod::ScreenSpace` + `screenSpaceSteps`（1–32）、`screenSpaceRadius`、`screenSpaceThickness`；JSON/UI/状态与 `RenderFeatures::ScreenSpaceGI` 均已接入。

## 渲染实现

`Shaders/Private/Scene.hlsl` 拆成两个 pass：

1. `SSGI trace`：
   - 读取当前帧 position/normal G-buffer；
   - 每个像素沿半球方向做固定/随机化步数的世界空间屏幕追踪；
   - 命中校验距离与法线；拒绝过亮 emitter-like 像素；
   - 命中时采样 **上一帧 direct-lit colour**（t16，不含 SSGI），避免 self-feedback；首帧历史无效时输出 0。
2. `SSGI composite`：
   - raw indirect（t18）做 3×3 几何加权空域滤波；
   - 用当前世界位置 + 上一帧 ViewProjection 重投影上一帧 indirect history（t19），clamp 到当前邻域后按 10% 当前帧权重混合；
   - 按接收面 albedo 调制，与当前 direct colour（t17）相加；
   - 写回 scene color，并把 denoised indirect 写入下一帧 history。

资源/常量：

- `GlobalIlluminationConstants`（b6）扩展为 112 字节：`giPreviousViewProjection`、`giHistory`（valid/frame/current weight/spatial taps）。
- Scene targets：direct history/current（RGBA8）、raw/history read/write indirect（RGBA16F）；SSGI 只在 editor/offscreen 启用。
- D3D12 RHI sampled slots 扩到 20，支持 t16–t19。
- `GlobalIlluminationStatus` 仍通过 lastGiMethod/lastScreenSpaceGi 返回 requested/effective/reason。

## 限制

- 在 display-space 颜色上合成，不是线性 HDR SSGI；
- 屏幕空间命中看不到屏幕外信息；快速相机运动有历史滞后；
- 无对象/发光 ID G-buffer，使用亮度阈值拒绝 emitter-like 像素；
- Forward、runtime swapchain 未启用；DXR 传输同帧跳过 SSGI。
