# M2：SSGI（Screen Space GI）

状态：完成首版（Deferred 光栅路径，D3D11／native D3D12 已验证）
提交：`1768b21`（引擎）、本地记录本提交
基线：M1 完成于 `1a3dc57`

## 范围

新增 `GlobalIlluminationMethod::ScreenSpace`，不依赖 DXR：

- `GlobalIlluminationSettings` 增加 `screenSpaceSteps`（1–32）、`screenSpaceRadius`（>0–100）、`screenSpaceThickness`（>0–10）。
- `.raproject` 读写 `"method": "screenSpace"` 及三个字段；旧项目缺省 8／2.0／0.2；非法值拒绝且保留原 manifest。
- Project Settings：GI method 增加 Screen space (SSGI)，只在非 Disabled 时允许编辑；显示 SSGI 参数；状态区显示 effective SSGI 与原因。
- RenderFeatures：新增 `ScreenSpaceGI`；Deferred 且无 DXR 传输时 Active，Forward 报告 Blocked。

## 渲染实现

`Shaders/Private/Scene.hlsl` 的 `PSDeferred`：

1. 读取当前帧 position/normal G-buffer；
2. 从每个像素沿半球方向做固定步数的世界空间屏幕追踪；
3. 投影像素后读取当前 positionBuffer 校验命中距离与法线；
4. 命中时采样 `screenSpaceHistory`（t13，上一帧已着色颜色）；首帧/无历史时 `giScreenSpace.x=0`，不产生贡献；
5. 结果按 `indirectDiffuseIntensity` 加到 Deferred 颜色，直接光保持不变。

`GlobalIlluminationConstants`（b6，32 字节）扩展：

- `giViewport`：effective 标志、宽、高、SSGI steps
- `giScreenSpace`：可用标志、半径、厚度、强度

SceneRenderer：

- 新增 RGBA8 `ssgiHistoryImage`，随 scene targets 创建/退役；
- DeferredLighting pass 增读 t13（`screenSpaceGi` 时）；
- 帧末把最终 scene colour 复制到 history；D3D11 用 `CopyResource`，native 用 `copyTextureRegionTo`；
- `viewId` 变化/尺寸变化清空 history；仅 editor/offscreen 场景目标启用（runtime swapchain 暂不启用）；
- D3D12 RHI sampled slots 13→14，支持 t13；
- `GlobalIlluminationStatus` 通过 lastGiMethod/lastScreenSpaceGi 返回 requested/effective/reason。

限制（已在公开文档写明）：SSGI 的一次屏幕追踪使用**上一帧颜色**，相机快速运动有一帧滞后；无时域重投影/空间降噪；Forward 路径不可用；DXR 传输同帧跳过 SSGI；runtime swapchain 路径未启用。
