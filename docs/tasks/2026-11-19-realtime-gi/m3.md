状态：完成（Deferred 光栅路径，D3D11／native D3D12 已验证；网格世界格点对齐、3×3 probe 更新、置信度 alpha）

## 范围

新增 `GlobalIlluminationMethod::ProbeGrid`：

- 配置：`probeGridX/Y/Z`（2–32）、`probeSpacing`（>0–20）、`probeHysteresis`（0–1）；`indirectDiffuseIntensity` 作为强度。
- `.raproject`：`"method": "probeGrid"` + 上述字段；旧项目缺省 16/8/16/1.0/0.95。
- Project Settings：GI method 增加 Probe grid (DDGI)，探针网格 X/Y/Z、间距、历史混合控件；状态区显示 effective DDGI。
- `RenderFeatures::ProbeGridGI`：Deferred + 无 DXR 传输时 Active，Forward 报告不可用。

## 渲染实现

probe atlas：

- 两个固定 1024×32 RGBA16F 的 2D atlas 做 ping-pong（width = X×Z，height = Y，覆盖最大 32³ 网格）。
- 网格原点由 `cameraTarget` 居中并**对齐到 `probeSpacing` 世界格点**，相机目标小幅移动时 probe 不漂移；CPU 每帧上传 `ProbeConstants`（b9，48 字节）。

更新 pass（`PSProbeUpdate`，pixel shader index 11）：

1. 全屏覆盖 probe atlas；每像素对应一个 probe；
2. 由网格参数得到 probe 世界位置，投影到当前相机；
3. 采样当前 position/normal G-buffer，校验距离与屏幕范围；
4. 从当前帧着色颜色按法线余弦、距离和 3×3 屏幕 footprint 加权得到辐照度；
5. 用 `probeHysteresis` 与上一帧 atlas 混合，alpha 写入 probe 有效置信度；
6. pass 结束后交换 atlas，`probeAtlasValid=true`。

消费：

- `PSDeferred` 在 `probeParameters.x/y` 有效时，用三线性权重从上一帧 atlas 采样 8 个相邻 probe，按 alpha 置信度加权，把辐照度乘强度加到间接漫反射；直接光与阴影保持不变。
- 首帧 atlas 无效，第二帧开始贡献；网格按世界格点对齐，相机目标跨越格点时才移动。

管线：

- 新增 `RenderPassKind::ProbeUpdate`（Deferred only）和 `PipelineResource::ProbeAtlas`；DeferredLighting 读 `ProbeAtlas`，ProbeUpdate 写 `ProbeAtlas`，ProbeUpdate 读 SceneColor/SceneDepth/GBufferNormal。
- D3D12 RHI sample slots 14→16、constant slots 9→10；D3D11 绑定 b9。
- 仅 editor/offscreen 场景目标启用；runtime swapchain 暂不启用；DXR 传输同帧跳过 DDGI。

限制：probe 更新使用屏幕空间可见性近似而非逐 probe 光线追踪；屏幕外/被遮挡 probe 保留旧值；近镜面间接不参与；Forward 不可用；网格随相机目标重建可能抖动。
