# M4：ReSTIR 采样层（首版）

状态：首版可运行／可配置（Path tracing 实时模式）；**不是完整 spatiotemporal ReSTIR**
提交：`9dd0639`（引擎）
基线：M3 DDGI 完成于 `f52eb1f`

## 范围

`GlobalIlluminationSampling`：

- `uniform`（默认，保持旧逐灯/逐路径采样）
- `restir`：加权 reservoir 采样层
- 配置：`restirCandidates`（1–16）、`restirDirect`、`restirIndirect`
- `.raproject` 读写 `sampling`、`restirCandidates`、`restirDirect`、`restirIndirect`
- Project Settings：`Sampling` 下拉、候选数、direct/indirect 开关；状态消息追加 `Sampling: ReSTIR (...)`。

## 实现

打包：`HardwareConstants.traceOptions.w` 编码候选数 + direct/indirect 标志，保持 208 字节布局。

Direct（`PathTracing.hlsli::PathDirectLightReservoir`）：

- 每个 shading point 从非矩形灯中均匀采样 `restirCandidates` 个候选；
- 每个候选计算与旧 `PathDirectLight` 相同的 BRDF×irradiance×shadow 贡献，并乘灯数得到候选估计；
- 按亮度做加权 reservoir 选择，输出 `selected * totalWeight/(selectedWeight*candidates)`；
- 矩形灯继续走独立面积光 MIS 估计器。

Indirect（`HardwareRayTracing.hlsl` trace batch）：

- 每像素计算 `restirCandidates` 个路径候选（`PathRadiance`）；
- 按亮度加权 reservoir 选择，输出候选平均的 reservoir 估计；
- 原 `samplesPerFrame` 历史预算仍由 `pathAccumulation` 累积。

时间稳定：沿用现有 GI 历史（`pathAccumulation`）与 temporal denoise；**没有独立 reservoir 历史、没有空间 reuse**。

- CTest 30/30（含 DDGI/SSGI 回归）。

## 已知缺口（下一轮）

1. 独立上一帧 reservoir + 时间重投影 reuse，而不是只靠路径累积；
2. 空间 reuse / 邻域 reservoir 合并；
3. reservoir 目标函数与光源选择 PDF 的严格无偏实现（当前直接光乘灯数并做 reservoir 校正，是近似）；
4. indirect 候选按亮度选择会偏向亮样本，需目标/PDF 校正；
5. 拖影/闪烁量化与 Uniform 对比基准。

完成这些后才可宣称完整 ReSTIR DI/GI。当前是**可配置、GPU 运行验证的 ReSTIR-style 首版**。
