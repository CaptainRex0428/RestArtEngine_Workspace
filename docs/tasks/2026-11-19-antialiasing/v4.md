## 分析

Codex 中断后引擎无法正常打开：编辑器窗口从加载尺寸 `963x542` 调整到 `2768x1191` 时，D3D12 RHI 拒绝 `ResizeBuffers`，报 `Release borrowed swapchain images before resizing the window.`。诊断打印显示当前 backbuffer `use_count()==2`。

追踪确认根因：`AntiAliasing.inl::executeAntiAliasing` 把 `pass.colors[0].texture` 写入持久成员 `aaResolvedImage`。FXAA 的输出就是调用者目标，非编辑器渲染时即交换链；该成员跨帧保留了一个交换链引用，`SceneRenderer::resize` 只重置了 `swapchainImage`，于是 `ResizeBuffers` 仍然看到借用。另有两处脆弱点：resize 前未释放 UI descriptor 借用，`pendingObjects_` 可积累数百个延迟释放对象。

## 修改

- `src/Renderer/AntiAliasing.inl`：`aaResolvedImage` 只在 TAA 时保存历史输出；FXAA 不再缓存目标／交换链。
- `src/Renderer/D3D12/D3D12Rhi.{h,cpp}`：新增 `releaseBorrowedUiTextures()`，在 resize 前结束 pass、清 pass/table/pipeline、`waitIdle`，并清 `uiBorrowedTextures_`、`pendingObjects_`、`pendingAllocations_`。
- `src/Renderer/SceneRenderer.cpp`：原生 D3D12 resize 先 reset `swapchainImage`、释放 UI 借用，再调用 `ResizeBuffers`。
