# v2 — TAA 亚像素重建修正

状态：静态改善，移动质量未通过。
基线：v1 Debug 成功构建但严格 D3D11 静态 TAA 质量失败；前一版 [v1](v1.md)。

## 分析

TAA 48 帧边缘 MAE 29.7711 高于 Off 23.3292，FXAA 15.7821。实际 GPU 图像中细线不连续。当前把当前 jittered inverse VP 与前帧 jittered VP 组合，会把静态场景颜色历史也跟随 jitter 坐标重投影；深度轮廓拒绝又可能阻止前景／背景覆盖率累积。需验证、修正采样与历史坐标，不能通过放宽质量阈值验收。

## 修改与验证

渲染与调查 agent 均遇工具 provider 429 重试耗尽，主 agent 接管代码。保持历史在非抖动输出网格，用 jitter 像素偏移双线性采样当前颜色，前帧矩阵改为非抖动 VP。CBuffer 不变；远面 clear-depth 判断改为 1.0，4 条遮蔽警告改名修复。Debug 引擎／管线重建无警告，CTest 2/2。

严格 D3D11 GPU 自测 exit 1：两路径 Off 23.3292、FXAA 15.7821、TAA 22.2368；静态已有改善，但移动 TAA 27.8843 超过 Off 23.2657 的 1.1 倍阈值。证据 `artifacts/antialiasing/v2/d3d11/`。v1 构建上真实 UI 自测已通过（Off／FXAA／TAA、按住 slider 从 .26 到 .71、保存往返和后端／GI 保留、Black／DarkBlue／560宽图），图形错误 0；截图已检查。这不替代后续最终代码 GPU 复验。

尚未通过移动质量。下一版 [v3](v3.md) 修正无 jitter 的相机 motion 与轮廓 depth dilation，保留原质量阈值。
