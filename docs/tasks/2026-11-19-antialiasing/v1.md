## 分析

用户先要求处理延迟 TAA，继而明确要各种抗锯齿方案，当前毛边严重。源码确认光栅没有 MSAA／FXAA／TAA；RHI 资源与 PSO 固定单采样。渐进路径追踪有随机主射线采样，实时 GI 不等价于光栅 TAA。

## 修改与验证

计划首轮 Off／FXAA／TAA，共享 RHI 全屏 Pass 位于景深之后、选中描边与捕获之前。工程默认 FXAA，裸 SceneSettings 默认 Off，保留工具／数据模式及已有像素自测基线。TAA 使用相机抖动、颜色和深度历史、重投影、深度拒绝及邻域限幅。没有运动矢量时场景编辑保守重置，不承诺完整动态物体 TAA。

DXR 的 HistoryKey 当前比较 VP，直接加入抖动会每帧重置 GI。因此实时 GI／硬件全图 resolve 请求 TAA 时明确使用 FXAA；渐进 PT 使用自身抗锯齿。不改写用户请求。工具预览不消费主视图历史。MSAA 的多采样附件、逐样本 GBuffer／resolve 属于后续独立实现。

Debug 引擎构建 exit 0，新增 4 条 C4458 参数遮蔽警告，渲染 agent 已改名待重建。工程 AA 配置与管线 CTest 2/2 通过。首轮严格 D3D11 实际 GPU 自测 exit 1：Forward 固定参考边缘 ROI 3666 像素，Off MAE 23.3292，FXAA 15.7821，TAA 48 帧 29.7711。TAA 比 Off 更差，不能验收；BMP 视觉确认细线存在断续珠状边缘。证据 `artifacts/antialiasing/v1/d3d11/anti-aliasing.json` 与同目录 BMP，构建日志 `build-engine.log`。
