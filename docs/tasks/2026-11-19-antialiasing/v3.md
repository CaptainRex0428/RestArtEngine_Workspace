# v3 — 稳定网格采样与轮廓深度膨胀

状态：修改后 GPU 验证中；前一版 [v2](v2.md)。

## 分析与修改

v2 当前帧先重采样导致细线过度模糊，移动仍不能达到质量阈值。当前采用原始 jittered sample 颜色在稳定输出像素累积，以前帧非抖动投影结果加当前 jitter 去掉 motion 中的采样偏移；3×3 最近表面深度用于相机重投影与遮挡判定，避免轮廓覆盖率交替被前景／背景拒绝。失效历史使用 FXAA 当前帧结果，运动提高当前帧权重，邻域限幅保留。
