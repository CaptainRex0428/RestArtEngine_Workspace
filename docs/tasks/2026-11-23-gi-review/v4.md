# v4 中档 DXR 探针的白斑与格纹

用户在 [v3 对照图](v3.md) 指出天花板和地板上的大块高亮，在首轮修正后仍能看出局部色块。本轮复用原来的 1281×721 Cornell 相机、曝光、AA 关闭、间接光强度 1，以及中档 12×6×12、每探针 16 条射线的预算。三后端均从日常使用的 Premake Debug 编辑器运行，底图 GI-off 在各次 D3D12 对照中逐像素匹配。目录均相对于 `artifacts/gi-review/blotches/`。

## 形成过程与修正

- 最初中档自动拟合按最长轴使用 1 米的等距网格，房间内只有 144 个探针。现使用按轴拟合的单元中心，间距为 0.433×0.667×0.433 米，864 个中心中 840 个落在房间开放空间，24 个在球内。薄场景限制单元长宽比，手动网格继续使用统一间距。CPU、光栅及 DXR 的 b9 增加逐轴间距，历史键和探针调试图使用相同布局。
- 旧硬件探针会把 GGX 窄高光写入低阶 SH。硬件供光端改用直接漫反射与矩形灯四点可见性，对跖采样保留同一射线预算，距离矩按有效方向样本权重跨帧积累。
- 首轮 `fit-transport/` 减弱了墙面亮斑，但 +3 EV 下漫反射球内部有 20.78% 像素近黑。修正 L1 的负瓣截断后，各档球面 0/14,493 像素近黑。在 `reconstructed/` 的固定平面上仍能看出八邻居三线性插值的折线。
- 最终硬件查询用逐探针可见性加权的 27 点二次 B 样条混合线性 SH，再重建辐照度；屏幕路径仍用八邻居。保持硬件探针独立方向相位。消融试验 `coherent/` 的整网格共享旋转使中档地板、天花板 16 像素 RGB 曲率 P99 从逐轴 B 样条的 12.59%、8.24% 回升至 16.61%、12.05%，故放弃该试验。等距 B 样条对照只采用热编译环节之前保存的图像，单独夹具的运行中遇到新旧 b9 布局不同步，没有把该次作为完整通过。

## 真机验收

用 `--raster-gi-self-test --backend <backend> --project fixture/PathTracing_CornellBox.raproject --capture-dir blotches/verified/<backend>` 检查 D3D11（6 组）、混合 DXR（12 组）和原生 D3D12（12 组）。三份报告均通过，图形验证错误为 0，包含热编译成功、失败保留、恢复和间接强度恢复。CMake、Premake Debug 构建成功，CTest 30/30。原生 D3D12 的中档 DXR dispatch 中位数 0.334 ms，DDGI 合成 0.446 ms，RTX 5060，16 个有效样本。两段分开计时。D3D12 的红墙换蓝墙仍使 125,211 个地板像素的 R 均值下降、B 均值上升。

使用引擎 `scripts/Test-DdgiImageQuality.ps1 -CaptureDirectory <捕获目录>` 检查标准相机。下表为显示图上移除平滑二次趋势后，相距 16 像素的亮度二阶差分 P99，占该区域平均亮度的百分比。

| 中档 +3 EV | 天花板 | 地板 | 球内近黑 |
| --- | ---: | ---: | ---: |
| 原始 `../delivery/d3d12` | 19.28% | 35.97% | 0% |
| 第一阶段 `reconstructed/d3d12` | 9.79% | 15.00% | 0% |
| 最终 `verified/d3d12` 和混合 DXR | 7.45% | 12.16% | 0% |

最终原生 D3D12 有 29 张图与选定空间重建候选的对应文件 SHA-256 相同。另取相邻帧及再过 97 帧的图。六个平面区域相邻帧的亮度平均绝对变化为 0.38/255，初帧与 +97 帧为 0.94/255。地板的宽缓横带仍在；独立 CPU 参考的约 147 万条余弦半球射线也得到开口侧较暗、靠近两侧墙面偏红或偏绿的趋势。参考与 GPU 的地板开口／内部亮度比为 0.426／0.567；天花板为 0.590／0.517。灯面背后 4 厘米的受遮挡点仍有明显漏光。这是低频探针与六方向距离矩的限制，完整参考条件见 `reference/README.md`。

在现有工程的独立副本还分别用普通 `--no-ui --deferred --frames 40` 启动保存的设置和会话级 `--hardware-rt`。原生 D3D12 两次实际分别执行屏幕探针及 DXR 探针，验证错误均为 0。最终设置页的 `--project-settings-self-test` 亦通过原生 D3D12 的档位点击、自定义恢复和保存重载，见 `verified/ui/hardware-rt-report.json`。工程原件保留。引擎改动尚未提交。
