# v8 DDGI 与独立金属反射

2026-11-25，Windows Debug x64，基于公开引擎 `8f7dd2c` 及前几轮工作区 GI 更改。先前 [v7](v7.md) 修复 SSGI 天花板弧带。本轮目标是让 Cornell 金属球同时反射其他物体和墙色，并可以分别控制探针漫反射与物体倒影。引擎源码留在工作区。

## 原因与方法

旧组合只将探针辐照度乘以接收面颜色及非金属权重。Cornell 环境强度为零，纯金属因此主要剩下直接灯高光。2019 年 DDGI 原文同时展示了独立的光泽射线项。现按此分工复用引擎的 SSR 和 DXR 一次镜面命中着色，反射未命中的比例采环境。DXR 可命中屏外几何；SSR 查当前 G-buffer 和线性 HDR 光栅结果。引擎的 SH 和分段屏幕追踪与论文算法的区别、生产化 DDGI 的高阶粗糙反射方法及来源见公开引擎 `docs/GlobalIllumination.md` 的“实时镜面反射”和“论文与方法”。

Deferred 的 Lit／GI indirect 支持仅探针、仅镜面、两项同开、两项同关。GI probes 视图临时只更新和显示探针。双开 DXR 时同一提交复用顶层加速结构，使用独立常量、输出与绑定执行两次 dispatch；纯镜面跳过探针。实时开关与 SSR 参数复用现有项目字段，F3 的实际来源行分别显示 SSR、DXR、Off。

## 实际 GPU 验收

隔离的 Cornell 场景复制到忽略目录。使用新编译的 Debug 可执行文件运行 `--raster-gi-self-test --hardware-rt --backend <backend> --project <fixture> --capture-dir <output>`。严格 D3D11、D3D11 + DXR、原生 D3D12 分别通过 6、12、12 个原有预算配置和新增 DDGI 反射组合。三份报告均 passed，图形验证错误为 0。原生和混合均实际执行两次 DXR dispatch 的组合。套件同时覆盖通道切换、探针调试恢复、失败保留与成功热编译。原生 D3D12 的 `--project-settings-self-test` 实际点击镜面开关、调整 SSR 距离、保存和重载成功。

固定 1281×721 机位。原材质 Lit 对照分别展示 Medium DXR 探针、加 SSR、加 DXR。默认 SSR 为 2 m／8 步／0.2 m。远墙改色另用 8 m／32 步／0.2 m，GI indirect 的额外诊断曝光为 0 EV。纯金属掩模由 G-buffer 金属度等于 1 的区域内缩 2 像素得到，共 32,923 像素。下表来自运行报告，RGB 和平均绝对误差（MAE）以 0–1 的显示图像值计算。

| 原生 D3D12 路径 | 红墙换蓝后红通道下降 | 蓝通道上升 | 关闭漫反射后的金属 MAE | 地板 MAE |
| --- | ---: | ---: | ---: | ---: |
| 屏幕探针 + SSR | 0.01021 | 0.01050 | 0 | 0.02124 |
| DXR 探针 + SSR | 0.01021 | 0.01050 | 0 | 0.04184 |
| DXR 探针 + DXR 镜面 | 0.00634 | 0.00653 | 0 | 0.03988 |

另外用原生 D3D12 的 19° 视角放大金属球，让左墙完全离开主相机，只开启镜面。对同一屏外墙做红蓝替换，关闭反射的 Lit 及 Albedo 分别逐像素相同。DXR 间接视图内有 107,427 个纯金属像素变色，SSR（8 m／32 步）为 0。九次运行图形验证错误均为 0，统计排除标题栏。成对截图、相机、金属掩模与全图测量在 `offscreen/offscreen-reflection.json`。

在 1281×721 的标准机位、RTX 5060、相同 Medium 配置下，预热后每个模式采得 16 个独立硬件计时。仅探针、仅反射、同帧两者均开启，原生 D3D12 分别为 0.314、1.693、1.979 ms，混合后端为 0.319、1.692、1.977 ms（中位数）。这些区间覆盖 DXR dispatch，完整帧还包含场景准备、光栅、合成和同步。

Premake Debug x64 与 CMake Windows Debug 均已生成程序，CTest 30/30。五个受影响的像素入口通过 FXC (ps_5_0) 与 DXC (ps_6_0，警告作错误) 离线编译，FXC 仍有原有 PCSS 循环变量及分支可能未初始化警告。三个后端的 `Test-SsgiCeilingImageQuality.ps1` 通过，两个 DXR 后端的 `Test-DdgiImageQuality.ps1` 通过。原生 D3D12 天花弧带落差 P90 为 6.41（屏幕）和 3.12（DXR 组合），探针天花和地板格纹 P99 为 7.20% 和 11.62%。

额外使用混合后端执行 `--gi-self-test` 回归渐进／实时路径追踪，1,117 次 DXR dispatch，图形验证错误为 0。首次增量 CMake 链接遇到独立冒烟进程占用旧可执行文件的 LNK1168，进程结束后正常重新链接，最终两套 Debug 构建均通过。

图像、JSON、GUI 验收及构建日志均位于引擎忽略目录 `artifacts/gi-review/ddgi-reflections/`，对照图是 `cornell-metal-reflections.png`。当前的一层倒影不包含命中物体的完整间接光。无 Vulkan、OpenGL、Linux 或 macOS 的 GI 实测；三个后续 GI 方案继续由[开发状态](../../DevelopmentStatus.md)追踪。[验证经验](../../experience/RealtimeGiVerification.md)
