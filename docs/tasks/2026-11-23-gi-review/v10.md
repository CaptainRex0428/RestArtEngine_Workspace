# v10 软件 GI 的可见颗粒与金属球倒影缺口

2026-11-25。用户用关闭硬件光追的两个倾斜视角圈出了天花板和右侧金属球。v9 已改善大色斑与首帧响应，但之前以 8／32 像素块为单位的统计会平均掉可见的细颗粒。分别回读纯探针、屏幕漫反射、纯镜面和完整 Lit：DDGI 单独看主要是宽缓色块，两个模式的粗糙 SSR 均产生局部细颗粒；SSGI 首帧还能看见来自左球供光的离散亮点。

## 修改和取舍

- 软件 SSGI 在半分辨率新增按几何约束的连续 7×7 漫反射滤波。合成以 3×3 重建全分辨率，避免重复全分辨率宽核加载。开启软件漫反射时才分配和调度滤波目标，原始历史与即时重建分开。
- 软件 DDGI 按活动网格的每轴分辨率选一格或两格的半径，拒绝穿过可见阻隔面的邻居，在密集网格上用球形邻域重建当帧 SH。30³ 的测试配置最多取 81 个探针，实时编辑后直接出光。
- 软件 SSR 的步段末端可能在实际交点外或屏外。将射线裁至视锥，允许相邻区间重叠寻找平面，再重投影核实交点，按屏边与距离渐退。近镜面保留窄的双线性重建。只做步进和空间重建时，斜视粗糙天花的纯镜面 9 px 亮度残差 P95 从 3.44 降到 2.73。最终在当帧按粗糙度发 1、2 或 4 条分层方向射线，P95 再降到 1.05，同时保留原平均亮度的 97%。

## GPU 回读

相同 Cornell 场景、机位、材质和曝光，严格关闭 DXR，FXAA，间接光强度 3.61，1281×721。新增 16 帧转动相机的回读，停稳 64 帧后在同一终止机位回读法线并排除轮廓。下表为 RTX 5060、D3D12 主光栅渲染。细颗粒用天花内部像素相对 9×9 邻域均值的绝对亮度残差 P95，单位是 8 位显示码值。

| 指标 | SSGI v9 → v10 | 软件 DDGI v9 → v10 |
| --- | --- | --- |
| 完整 Lit 首帧颗粒 | 1.56 → 0.61 | 1.28 → 0.51 |
| 转动相机第 16 帧 Lit 颗粒 | 1.27 → 0.55 | 1.08 → 0.43 |
| 首帧纯漫反射的天花平均亮度 | 56.73 → 56.71 | 20.58 → 20.92 |
| 全部效果开启，主光栅 GPU 区间中位数（16 帧） | 1.87 → 1.88 ms | 1.97 → 2.66 ms |

独立镜面在 2064×1191 窗口回读验证。右球 18° 的绿墙、18° 的地面、27° 的地面倒影内部暗孔面积分别从 120／82／601 像素降至 0。三个区域的反射信号总量分别保留 98.4%／86.9%／95.8%。屏幕边缘的退场也会改变某些倒影轮廓。软件 GI 仍以可见 G-buffer 为供光来源，首帧仍有低频起伏。本次仅覆盖 Cornell，移动镜头和光照阶跃已有回读，动态角色与其他 GPU 型号还需另验。

Windows CMake 和 Premake Debug 构建通过，CTest 30/30。原生 D3D12、严格 D3D11、D3D11 + 可选 DXR 配置均做了软件专测和 raster GI 回归。支持 DXR 的配置另测硬件镜面与探针。图像/数据在引擎忽略目录 `artifacts/gi-review/software-noise/refined/` 和 `artifacts/gi-review/software-realtime/ssr-rings/ssr-final-metrics.json`。回归命令与图像指标在公开 `docs/GlobalIllumination.md`。
