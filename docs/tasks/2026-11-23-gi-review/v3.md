# v3 接收面、实际执行路径与性能分档验收

承接 [v2](v2.md)。基线为引擎 `8f7dd2c` 加本任务的工作区修改。Windows Debug，RTX 5060。Cornell Box 和 Sandbox 使用从基线提取的隔离工程副本。测试的材质草稿只存在于内存。

## 验证方式

用 CMake 和 Premake 构建 Debug。CMake 构建目录运行 `ctest --test-dir build/gi-review -C Debug --output-on-failure`，30/30 通过。GPU 验收使用 Premake 产物 `bin/windows-x86_64/Debug/RestArtEngine.exe`。从忽略目录 `artifacts/gi-review/` 运行下列命令，分别写入三个报告。夹具保留项目的硬件请求，让严格 D3D11 实际执行屏幕路径。

```powershell
foreach ($backend in @('d3d11','d3d12','d3d11Dxr')) {
    & $exe --raster-gi-self-test --backend $backend --project fixture/PathTracing_CornellBox.raproject --capture-dir "delivery/$backend"
    if ($LASTEXITCODE) { exit $LASTEXITCODE }
}
```

每个预设校验首帧与稳定帧、实际路径与特性矩阵、零增益回到光栅基底、间接光调试曝光；改变 GI 预算须丢弃 TAA 的旧历史，Forward 的暂停状态允许 TAA 正常继续累积。热编译试验包括错误材质保留旧图，合法的全黑接收材质使间接漫反射归零，恢复 Shader 后间接光再次可见。

最终三份 `delivery/<backend>/raster-gi.json` 的 `passed` 均为 true，图形验证错误均为 0。严格 D3D11 覆盖 6 组，原生 D3D12 与混合 DXR 各 12 组。两个硬件后端的三个探针档位均各取得 16 个有效 DXR 调度计时样本。

## 颜色和显示

在同一相机和曝光下，将一面墙的红、蓝通道互换。两种颜色各渲染 24 帧，用 G-buffer 法线和金属度筛选出 125,211 个地板像素，读取间接光显示图的归一化 RGB。以下是原生 D3D12 的读回均值，G 通道在各组内一致。

| 路径 | 红墙时地板 R / B | 蓝墙时地板 R / B |
| --- | --- | --- |
| SSGI | 0.0524 / 0.0325 | 0.0328 / 0.0517 |
| DDGI 屏幕探针 | 0.0421 / 0.0275 | 0.0278 / 0.0415 |
| DDGI 硬件探针 | 0.0837 / 0.0597 | 0.0608 / 0.0821 |

中档同视角四列对照在 `delivery/cornell-gi-comparison.png`。上排为场景曝光，下排为单独显示间接光并提升 3 EV。用于拼图的七张原生 D3D12 原始图与最终二进制的对应图逐文件 SHA-256 一致。SSGI 仍有采样颗粒，屏幕探针会遗漏视野外几何；硬件探针可捕获视野外几何，低密度网格仍有明暗过渡及薄壁漏光风险。

## GPU 时间

1281×721，Deferred，AA 关闭，间接漫反射强度 1。原生 D3D12，Cornell 固定视角。每档丢弃预热，以下各项取 16 个唯一 GPU 时间戳结果的中位数。软件路径的数值涵盖主光栅帧；硬件探针一行只计 DXR 的 dispatch。报告另列合成、RHI 时间戳以及含 CPU 和同步的墙钟时间。

| 毫秒 | Low | Medium | High |
| --- | ---: | ---: | ---: |
| SSGI 屏幕路径，主光栅帧 | 0.74 | 1.17 | 3.45 |
| DDGI 屏幕探针，主光栅帧 | 0.51 | 0.51 | 0.59 |
| DDGI 硬件探针，DXR dispatch | 0.07 | 0.16 | 0.27 |

SSGI 半分辨率漫反射方向数 × 最大步数为 2×6、4×12、8×24。DDGI 三档每帧探针射线数为 2,048、13,824、65,536。全分辨率 DXR 镜面在此场景单独约 0.60 ms。硬件时间戳在实际 dispatch 前后写入，带源帧号，复用既有 fence 读回。

## 相邻回归与证据

- `v5/ui/hardware-rt-report.json` 和 `delivery/ui/hardware-rt-report.json` 分别记录原生与混合后端的真实 ImGui 点击、切档、Custom 值恢复、上一场景帧状态、临时 EV、探针图及保存重载。最终混合后端使用 `--project-settings-self-test --backend d3d11Dxr --project ui-fixture/Projects/Sandbox/Sandbox.raproject --capture-dir delivery/ui`，通过且图形验证错误为零。
- `v3/native-regression/native-d3d12-report.json` 的 8 项检查、`v3/hybrid-regression/hardware-rt-report.json` 的 13 项检查通过。两份报告的图形验证错误均为零。
- `runtime-screenSpace.log` 与 `runtime-probeGrid.log` 分别记录原生 D3D12 的普通 `--no-ui --frames 8` 运行。两者按项目配置关闭 DXR，实际 GI 方法与请求一致，验证错误均为零。
- CMake/Premake 构建、CTest 和最终三个 GPU 后端的控制台日志位于 `artifacts/gi-review/*-delivery.log`。历次图像和报告保存在同目录下的 `v3`、`v4`、`v5` 与 `delivery`。引擎源码尚未提交。Windows 以外平台和 Vulkan、OpenGL 未交付实时 GI 执行路径。
