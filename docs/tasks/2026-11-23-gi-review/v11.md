# v11 软件 GI 的动态更新、空间滤波与屏外供光

2026-11-27。引擎基线 `380a447`。实现分别在 `5cd9ab7`、`a3ac5e3`，测试和技术说明在 `800dc4a`。

## 方法

- 独立屏幕空间 DDGI 在冷启动和场景输入变化时全量更新。稳定 16 帧后，每四帧覆盖全部探针，SH 亮度变化较大的探针获得额外更新。迟滞为零时仍全量更新。Cornell 的 30³×32 配置在稳定时将每帧提交槽位上限从 864000 减到 432000，这个数是预算上界。
- SSGI 追踪输出当前射线估计的相对标准误差，半分辨率滤波依据局部误差和历史重投影覆盖率选择 3×3 至 7×7 的有效范围。供光物移动和相机转动时使用宽核。原始时间历史、滤波结果与全分辨率合成各有独立用途。
- Software world GI 在 Deferred 中对可见 Actor 的实际三角形按材质槽保守体素化，光栅和软件 DDA 更新表面辐亮度，再投影到场景探针。静态几何复用缓存，改灯只重算表面光照，改色复用几何覆盖。低、中、高档最长轴分别为 16、24、32 格，自定义至 64 格。关闭漫反射或切出方法时释放场景体素资源。

## 屏外供光

窄视角内调换供光墙的红蓝底色，可见 Albedo 改变 0 像素。取样中性地板 7320 像素，朝向该墙的粗糙灰球 3417 像素。以下为红蓝通道平均差分之和，软件方法用间接光视图，256 spp DXR 用 Lit 作变化趋势参考。

| 接收面 | 软件近灯／远灯／隔板 | DXR 近灯／远灯／隔板 |
|---|---|---|
| 地板 | 0.19445／0.05481／0 | 0.18643／0.05096／0 |
| 灰球 | 0.06242／0.02367／0 | 0.09098／0.04852／0 |

严格 D3D11、原生 D3D12 的世界探针结果一致。混合 D3D11/DXR 的 Project Settings 测试用实际 ImGui 控件选择算法、切档、拖动迟滞，切换间接光视图，保存并重载项目。参数在当前视口生效。

本轮覆盖静态网格的一次低频漫反射，体素密度限制了紧邻薄面和小于单元宽度的细节。几何变化需要重建覆盖，千万面动态重建、级联大场景和其他 GPU 尚无实测。构建、原始测量与图像留在引擎忽略目录 `artifacts/gi-review/adaptive-world/` 和 `artifacts/gi-review/world-space/final/`。

Windows CMake、Premake x64 Debug 及安装包检查通过。三个后端的光栅 GI、SSGI 天花板检查、可用 DXR 后端的 DDGI 像素检查，以及 Shader 热编译成功、失败回退和恢复均通过。Validate-Render 通过。全量 CTest 首轮发现 D3D12 单测仍将 b10 当作越界槽位。加入 b10 合法、b11 越界的检查后 31/31 通过，对应 `c7c0937`。
