# v2 诊断可见性、追踪成本与颜色传递验证

在 GI indirect 单独提供 0–4 EV 查看暗部，不改 Lit 或项目保存。把软件探针运输拆为每探针每射线一次屏幕追踪、单独投影到所有 SH 系数。两个实时算法的光栅基底共享原本的阴影和环境。修正旋转／非均匀缩放物体的 previous-world 矩阵乘序。补充 GI 质量变化时 TAA 的历史边界。

1281×721 定向测试在隔离的 Cornell Box 检查全帧／Pass 异步 GPU 时间、读回边界之间的墙钟均摊时间、首帧、实际档位、零贡献、调试曝光。首次以近等 RGB 的 Albedo 作为接收掩模，选到了金属球，SSGI 的红／蓝墙试验都返回零。该次检查失败，原始 `v2/d3d11/raster-gi.json` 保留。改用法线朝上的低金属度地板，再对比只有一面墙改变颜色时的地板 RGB；这项试验使用同一相机和相同历史长度。后续结果见 [v3](v3.md)。
