# v5 Cornell 录屏的频闪与硬件反射颗粒

状态：Cornell 的静态、灯光响应与图形回归已通过。引擎源码未提交。

基线为 `8f7dd2c` 加 [v4](v4.md) 后现有 GI 改动。三段录屏以 SSGI + DXR 反射和 DXR DDGI 展示同一场景。探针录屏使用 30³ 网格、每探针 32 条射线、迟滞 0.86、间接漫反射强度 5.78。单张截图的迟滞为 1，连续录屏能区分低迟滞波纹和固定空间格纹。

## 原因和实现

- SSGI 漫反射的低分辨率单帧样本较稀，亮供光面能在相邻帧之间出现或消失。每帧用稀疏邻域强制裁剪历史会放大这种变化。`ScreenSpaceGi.hlsli` 对相邻 2×2 追踪像素分层，按接收面从 3×3 邻域重建。运动向量投回的四个历史点独立验证深度。稳定期逐步累计最多 128 帧，场景运动和遮挡边界提高当前帧权重。`SceneRenderer.cpp` 用非抖动视图投影及可见 Actor 变换检测运动，覆盖供光物体移动而接收面静止的情形。
- DDGI 轮换方向时，每帧的 SH 和距离矩都会因采样略有不同。原迟滞在低于 1 时按固定比例混入噪声。屏幕和硬件现在共用 `ProbeLighting.hlsli` 的有界历史权重。迟滞为 0 时取当帧，正值在稳定期逐步扩大平均窗口，达到 1 时也持续采新样本，窗口最多 1024 次更新。DXR 的距离矩与 SH 使用同一时间权重。探针每帧射线预算沿用档位配置，灯光、几何、材质或网格变化仍可清空对应历史。
- SSGI 的硬件镜面没有时域累计。旧反射逐像素随机采 GGX 方向和矩形灯，形成金属球上的高频颗粒。`HardwareRayTracing.hlsl` 改为每个接收像素 1、2 或 4 条稳定反射射线，均查询 DXR 场景。近镜面走主方向，一般光泽面走 4 条固定偏移方向，低 Fresnel 粗糙非金属走 2 条按 3×3 九个采样层组织的对跖方向。光栅合成按法线、位置、粗糙度和金属度筛选邻域，合并辐射与命中比例。命中着色用锥宽修正高光，宽瓣矩形灯使用中心可见性与有限立体角近似。

粗糙表面全部使用四条固定射线曾达到 3.31 ms。改为一条主方向仍约 2.63 ms，且墙上出现明显的镜像圆斑。三方向方案约 1.93 ms，出现固定重影。最终采用分表面采样及宽瓣重建，保留屏幕外几何的反射。

## 录屏机位前后对照

使用同一 Cornell 工程副本和相机，普通 `--backend d3d12 --deferred --no-ui --frames 112 --capture-dir <输出>` 路径输出 2768×1191 Lit，开启 FXAA 并固定曝光及间接漫反射强度 5.78。临时采集入口只将截图扩展至第 96–111 帧。取天花板 `(1032,72)–(1728,264)` 半开区域，计算 8×8 色块均值在 16 帧内的峰峰值 P95。以下亮度单位均为 8 位码值。

| 分支 | 天花板色块极差 P95 | 天花板平均亮度 |
| --- | ---: | ---: |
| SSGI + DXR 反射 | 12.43 → 0.77 | 19.37 → 21.18 |
| DXR DDGI，迟滞 0.86 | 9.27 → 0.81 | 104.97 → 103.74 |
| DXR DDGI，迟滞 0.50 | 28.71 → 4.38 | 105.01 → 104.55 |
| DXR DDGI，迟滞 1 | 0.76 → 0.76 | 103.73 → 103.73 |
| 屏幕 DDGI，迟滞 0.86 | 14.24 → 1.27 | 13.83 → 13.84 |

SSGI + DXR 天花板的相邻帧单像素差 P95 从 11.00 降为 0.72。金属球下半部同一选区的亮度四邻高频残差，缎面从 3.15 降为 0.41，镜面从 4.03 降为 0.78。

隔离夹具另在第 134 帧关灯，第 142 帧开灯。DXR DDGI 天花板均值当帧从 103.56 降至 0、开灯后当帧回到 103.81。SSGI 漫反射对应 20.82、0、20.10。之后 8 帧内相机逐步偏转 0.32 rad，静止后继续积累。响应测试使用本轮漫反射与探针实现，早于最后一次粗糙材质镜面调整。

## 拖动迟滞滑块

原先屏幕路径把整个 GI 配置纳入历史比较，DXR 又把包含迟滞值的四分量网格常量作为探针标识。拖动滑块会使历史失效并重复使用采样序列的第一个方向。现在只把网格的三维尺寸纳入这部分标识，同帧上传新迟滞，仍然保留布局、射线预算、灯光和几何的失效逻辑。

静止 120 帧后，将迟滞从 1 改为 0.86，再用 8 帧连续降至 0.50。使用相同的 5.78 倍增益与天花板区域，从 1 到 0.86 当帧的相邻帧色块亮度差 P95，DXR 从 24.89 降至 0.26，屏幕探针从 18.50 降至 0.16。该对照用于检验滑块触发整卷重置的问题。

反向调节时，SH 图集的 alpha 记录探针保留的有效历史长度，新窗口每帧最多增加一个样本。DXR 的方向可见性与光照使用同一权重。第 121–127 帧将迟滞设为 0，第 128 帧恢复为 1。以第 120 帧稳定画面为参考，恢复 16 帧后，DXR 的 8×8 色块亮度偏差 P95 从仅保留历史、按总帧龄加权时的 21.89 降至 3.89，屏幕探针从 12.91 降至 6.48。两组均以正常渲染入口传入连续帧的设置。引擎内的 `hysteresisEdit` 用显式重置作冷启动参照，同时要求从 0 调回 1 后的全图 16 帧误差小于单帧误差的 65%。

## 引擎回归与成本

日常 Premake Debug 在隔离 Cornell 夹具运行 `--raster-gi-self-test --backend <backend> --project <夹具工程> --capture-dir <输出>`，混合与原生 D3D12 另传入 `--hardware-rt`。严格 D3D11 有 6 组，混合及原生 D3D12 各 12 组，图形验证均为 0 错误。保留互染、强度归零、热编译成功／失败保留／恢复检查。新增 `ceilingTemporal` 在中档用 3.61 倍间接漫反射与 FXAA，预热 32 帧后检查连续 16 帧。原生 D3D12 的色块极差 P95 分别为 SSGI 屏幕 4.53、SSGI + DXR 反射 4.65、屏幕探针 3.03、DXR 探针 0.66，均通过。CMake Debug、CTest 30/30 与离线 FXC／DXC 检查通过。FXC 在项目严格模式下仍报告一条既有的 PCSS 循环变量重名警告。

RTX 5060、1281×721、原生 D3D12 中档，16 个有效时戳样本。SSGI 的 DXR 反射 dispatch 中位数从 v4 的 0.632 ms 增至 1.714 ms，光栅 SSGI 合成由 0.254 ms 增至 0.436 ms。DXR DDGI dispatch 为 0.314 ms，DDGI 合成 0.448 ms。DXR dispatch 时戳只覆盖 dispatch。全帧成本还取决于加速结构、队列同步、输出分辨率和材质覆盖。

引擎忽略目录 `artifacts/gi-review/recordings/` 保存 `before-after.webp`、`recording-metrics.json`、`response.json`、`hysteresis-slider.json` 和 `hysteresis-recovery.json`。各后端最终报告位于 `accepted-*/raster-gi.json`，测试构建配置为 Debug。用户项目原件保留。

## 边界与经验

极低迟滞与高增益下仍有波动，屏幕追踪仍受可见域限制，DXR DDGI 对薄壁和狭缝仍可能漏光。场景编辑引起的探针局部失效、运动遮挡边缘的残影和其它场景的预算需要单独验收。稳定期、编辑响应、空间残留和分队列 GPU 成本分别统计，见[实时 GI 验证经验](../../experience/RealtimeGiVerification.md)。
