# v9 软件 DDGI 色斑与 SSGI 首帧响应

2026-11-25。在 Cornell 编辑器配置关闭硬件光追时，天花板和地面出现成片色斑，SSGI 在点亮或改灯后还要等很多帧。关掉 SSR 后，纯漫反射回读仍能复现。使用原机位、FXAA、3.61 倍间接漫反射强度，固定 1281×721。软件 DDGI 使用 30³ 探针、32 射线、24 步、迟滞 0.89。SSGI 用 4 条射线、8 步、2 m。

## 原因和取舍

原软件探针只比较步段中点与深度缓冲表面的位置，细网格的小容差使连续平面上的有效交点随机消失。沿步段求可见表面切平面交点并重投影，核实实际可见位置与法线，找回遗漏的供光。仅做命中修正时，首帧少量方向样本让更强的照明形成了更明显的色斑。继续给相邻探针分配互补方向，在当帧按几何阻挡重建 SH。投影的原始历史与显示滤波分别占用纹理，避免光照随帧数扩散。

SSGI 屏幕追踪与探针回退共同决定首帧能量。早期测试中稀疏的外环采样留下点阵，且粗网格的滤波范围随历史窗口快速变化，会带动地板平均亮度漂移。最终软件回退采用固定权重 0.8，SSGI 漫反射在连续 5×5 个半分辨率采样点上做几何引导重建，时间累积按重投影覆盖率与运动处理。静置历史窗口仍可逐渐增长到 128。SSGI 回退探针每档 12／24／32 射线，主 SSGI 追踪预算保持工程设置。

工程研究参考本地 Unreal Engine 的 LumenScreenProbeTracing、LumenScreenProbeFiltering、LumenScreenProbeGatherTemporal 与 SSRTDiffuseIndirect，分别关注交点再验证、空间复用和历史更新。引擎的 G-buffer、SH 探针和 HLSL 重建均按现有 RHI 独立实现。

## 画面、响应和成本

回读冷启动、改灯后第 1／4／8／32／64 帧的纯间接照明及 Lit 首帧、静置图。矩形灯横移 0.5 m 并将辐射强度乘以 1.65。使用法线选取三个平面的内部区域，以各方法第 64 帧作响应参考。以下原生 D3D12 数据来自正式脚本的方形掩模。亮度按 8 位显示码值计。

| 指标 | 原软件 DDGI → 当前 | 原软件 SSGI → 当前 |
| --- | --- | --- |
| 天花首帧 8 px 图块亮度二阶差分 P95 | 13.55 → 4.14 | 11.00 → 4.34 |
| 天花第 4 帧同指标 | 9.47 → 2.96 | 6.34 → 2.62 |
| 天花首帧距第 64 帧的 32 px 图块平均绝对亮度差 | 3.44 → 2.16 | 6.20 → 2.77 |
| 改灯后天花对新光照的响应，第 1／4／8 帧 | 63%／84%／88% | 84%／91%／95% |
| RTX 5060 主光栅 GPU 计时中位数（各 16 帧） | 1.41 → 1.98 ms | 1.28 → 1.88 ms |

当前软件 DDGI 的光线步进约 1.01 ms，独立 SH 滤波约 0.08 ms。当前 SSGI 合成约 0.87 ms。视口仍可在首帧天花看到宽缓的亮度起伏及少量细颗粒；这些数字不覆盖全应用耗时，也未验证屏外传输或所有场景。世界空间软件 GI 与金属镜面精度分别在开发状态中跟踪。

复现入口为 `--software-gi-self-test` 和 `scripts/Test-SoftwareGiResponsiveness.py`。本地基线和最终候选在引擎忽略目录 `artifacts/gi-review/software-realtime/{baseline,candidate-VI}/`。最终首帧 Lit 对照见 `candidate-VI/lit-first-frame.png`，各后端均有逐帧图与 JSON。

在 Windows 的原生 D3D12、严格 D3D11、D3D11 + 可选 DXR 三种启动配置中，关闭硬件的画质回归均通过，实测 DXR dispatch 与图形验证错误均为 0。混合配置的主光栅实际为 D3D11。另行开启设备支持的 DXR 路径，三份 raster-gi 报告全部通过，包括首帧、迟滞、颜色互染、独立金属反射、热编译失败保留／成功换图和 TAA 历史复位。三个后端通过天花弧带回归，两种支持 DXR 的配置也通过硬件 DDGI 图像回归。原生 D3D12 的软件／DXR 天花弧带落差 P90 为 2.72／3.20。Windows Debug CTest 30/30，7 个光栅 GI 像素入口分别通过 FXC ps_5_0 和 DXC ps_6_0 编译。
