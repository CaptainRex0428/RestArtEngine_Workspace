# v2 — 集成审查后的失败恢复

状态：主场景RHI切片已通过构建／专项GPU验证；首次完整Editor因夹具缺少项目.rasset未完成，转[v3](v3.md)修正验收夹具。
前一版：[v1](v1.md)。v1构建通过（3项局部变量遮蔽告警）；CTest24/24，包括实际WARP像素回读；五案例启动矩阵和三种strict输出一致通过。

## 分析

独立只读审查发现：ResizeBuffers失败后已释放RTV，旧尺寸重试被相等尺寸分支阻断；native Outline失败时RHI已无活动Pass，幂等end不会清native临时输出和blend。正常路径没有发现资源代际／候选热编译发布问题。

## 修改与验证

补充ResizeBuffers失败时重新获取旧swapchain目标；允许同尺寸缺失目标重新创建。渲染失败scope统一释放native临时输出、读取和blend；正常成功路径不改变。修复3处变量遮蔽告警。补充可选D3D11调试事件、移除被RHI管线替代的native材质状态创建，并将CPU视锥工具分离为FrustumCulling.inl。实际阴影采样绑定依逻辑Pass reads决定，G-buffer／背景不再绑定不消费的阴影。

## 结论与经验

此版针对失败恢复，不把已知正常路径通过外推为设备丢失恢复已实现。下一步旧新截图、完整混合DXR、GC与编辑预览回归。引擎未提交。
