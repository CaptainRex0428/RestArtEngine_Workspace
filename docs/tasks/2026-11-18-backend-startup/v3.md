## 结论与经验

用户明确需保留的混合模式应作为能力选择表达；兼容字段或实现历史不能变成产品里的功能降级标签。DXR 是 API 能力，ray tracing 是算法，两者不能混称。来源：[微软 DXR](https://learn.microsoft.com/en-us/windows/win32/direct3d12/direct3d-12-raytracing)、[D3D11 Compute](https://learn.microsoft.com/en-us/windows/win32/direct3d11/direct3d-11-advanced-stages-compute-shader)。
