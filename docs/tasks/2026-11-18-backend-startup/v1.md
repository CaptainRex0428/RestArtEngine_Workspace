## 分析

现有后端类只提供占位生命周期，App 实际直接创建 D3D11 SceneRenderer；DXR bridge 在 pipeline 初始化时无条件构造，关闭光追仍可能创建 12 设备。旧工程缺少主后端字段，不能一律按严格 11 解释而丢失既有 GI。

## 修改

- 增加无 API 依赖的启动策略，旧缺字段为 LegacyHybrid，Auto／11／12回退严格禁止 DXR 初始化；12禁止回退时在创建设备前拒绝。
- 工程保存请求后端与回退布尔，严格校验且原子保存，保留未知字段及 RT/GI 意图。
- App 接入命令行临时覆盖、真实设备初始化与启动状态；Project Manager 固定严格 11。
- 配置界面区分当前实际后端与下次启动草稿，继续沿用保存／脏状态流程。
- SceneRenderer 管理设备与失败清理，报告设备实际就绪和 D3D12 initialize 尝试；能力矩阵单列后端限制，避免误报“模块未编译”。
- 公开技术文档说明当前能力、配置及 CLI；不将本地方案或协作资料放到引擎库。
