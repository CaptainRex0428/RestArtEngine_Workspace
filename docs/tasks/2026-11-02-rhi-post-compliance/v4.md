# v4 — RHI DOF 与纹理拷贝

状态：通过
基线：`bd99a39`；平台 Windows / DX11；Debug x64
前一版：[v3](v3.md)

## 分析

DOF 需要读取目标自身的快照，再写回同一颜色目标；D3D11 原生实现用私有 `dofSource` 复制。RHI 缺少纹理拷贝，因此先补 `copyTexture`，再接 DOF shader。

## 修改与验证

### 修改

- `IRenderBackend::copyTexture`：DX11 `CopyResource`；DX12 以 COPY_SOURCE/COPY_DEST 屏障执行，目标回到 PIXEL_SHADER_RESOURCE。Base/Null 明确拒绝。
- 新增 `Shaders/Private/Rhi/DepthOfField.hlsl`、`RhiDofConstants`（48 B：viewport、focus/scale/maxRadius、near/far）。
- `SceneRenderer`：`debugView==0` 时复制 `SceneColor` 到 FP16 临时目标，t0 色/t1 深度写回 `SceneColor`；失败回退原生 `renderDepthOfField`。
- 场景 RHI 纹理改为带 RTV（DOF 目标）；新增 RHI 临时色目标、管线与常量；重载/释放纳入生命周期。
- `BackendSmoke` 在 DX11/DX12 验证 `copyTexture`；`TaaSmoke` 增加 DOF 开关图像差异检查。
- `BackendTests` 54 项（新增 copy 拒绝路径）。

## 结论

- RHI 后处理现在覆盖 Tonemap/Bloom/DOF/FXAA/Motion/TAA（普通视图，DX11）；调试视图 Tonemap/Bloom 仍走原生。
- `copyTexture` 是两个 API 通用的基础能力，后续读回/快照类 Pass 可复用。
- 剩余：DX12 仍不能导入场景 HDR/深度/历史；调试视图 RHI 化。
