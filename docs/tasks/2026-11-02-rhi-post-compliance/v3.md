# v3 — RHI Bloom 三 Pass

状态：通过
基线：`12cbfd6`；平台 Windows / DX11；Debug x64
前一版：[v2](v2.md)

## 分析

Tonemap 已消费 Bloom 纹理，迁移 Bloom 后整条显示链只剩 DOF 为 D3D11。Bloom 是三个全屏 Pass：阈值 → 半分辨率 Bright，H/V 高斯在 Bright↔Temporary 间 ping-pong。

## 修改与验证

### 修改

- 新增 `Shaders/Private/Rhi/BloomThreshold.hlsl`、`BloomBlur.hlsl`。
- `RhiBloomConstants`（64 B）：threshold/intensity/半分辨率 texel、模糊方向、viewport、全分辨率场景尺寸。
- 导入 `BloomBright`/`BloomTemporary` 为 FP16 RTV+SRV；阈值写 Bright，H/V ping-pong；源码与目标不重叠。
- `debugView==0` 时优先 RHI；数据调试视图保留原生 Bloom；失败回退原生三 Pass。
- `reloadShaders` 失效并重编 Bloom 管线；`releaseRhiPostResources` 释放 Bloom 纹理与管线。

## 结论

- 首版误把 Bloom 半分辨率纹理尺寸当作 viewport 分母，导致 Unlit 捕获变黑；改用全分辨率 `sceneSize` 后恢复；Unlit 等调试视图仍走原生 Bloom，避免直通语义分叉。
- 剩余：DOF 仍 D3D11；DX12 场景纹理共享未实现。
