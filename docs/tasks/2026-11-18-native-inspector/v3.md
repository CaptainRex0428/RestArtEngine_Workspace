# v3 — 实际显示通道回归与partial状态可见性

状态：渲染／通道修复通过，新增partial UI自测fixture访问异常；后续[v4](v4.md)。前一版[v2](v2.md)。引擎未提交。

## 原因与修改

v2实际Inspector两后端、UI双主题宽窄及跨API离线打开均通过，但完整hybrid Editor在Diagnostics的25个GPU显示通道检查失败。检查原始GBuffer/深度通过，RGB转换也正确；根因是新的CPU深度显示把三个RGB分量都变成线性深度后，单独选择G/B仍用了映射值。深度仅R有数据，G/B应为原始0，A为1。修改只对RGB及R应用相机解码，G/B/A保留原通道语义，不降低旧断言。v2失败证据`artifacts/inspector-v2/editor-regression.log`和`editor-regression/diagnostics/`保留。

新增公共同步`readCapturedDisplayPixel`读取实际GPU缓存的RGBA8显示纹理，与raw pixel API区分。Inspector专项逐资源检查全部RGB/R/G/B/A，包含本地和offline两次；两后端均使用各自真实readback，不能拿CPU转换公式自比代替GPU像素。顺带保持Unavailable GPU捕获身份为0，符合metadata契约。

审查还发现partial Draw详情过早return，隐藏了预算／未观察原因及仍保留的bindings。界面现显示原始pipelineState原因并允许检查已保存部分，缺失Viewport/Shader不显示为有效默认。完整状态控件不变；UI专项增加实际选择native Outline事件并断言原因可见。

v2的Debug无告警、CTest29/29、严格11 Inspector10组／12九组、两API UI实际输入与截图、双向离线打开和native12七组回归均通过；这些属于v2构建，不能覆盖当前修改。v3重建后重跑CTest、两个Inspector／UI、完整hybrid Editor和硬件光追，再检查非UI像素与用户资产／Premake。最终结果在本版补齐，原始证据`artifacts/inspector-v3/`。

v3 Debug构建通过，CTest29/29；实际Inspector严格11十一组／12十组通过，本地与offline各25个display通道像素通过，图形错误0。UI新增partial事件选择前发生access violation，最后产物为frozen Shader截图；测试缓存的ImGui table pool指针跨Constant table新建后使用，存在pool扩容失效。v4重新按table ID取InnerWindow，生产代码未因该fixture错误回退。证据`artifacts/inspector-v3/`保留，不把v3 UI写成通过。
