## 分析与修改

v1 模型回调布局更新后，增量程序在旧回调析构位置崩溃。使用同一源码完整清理重建以排除旧对象文件混入；不通过回退模型功能绕过。自测修正 renderer 尺寸访问和遮蔽变量，150% 用例同时缩放字体和控件尺寸，逐轮恢复样式避免累积缩放。

底栏沿用现有 GUI 主题与命令事务，尺寸计入 DockSpace；命令输入和 Output Log 在视口交互前提交焦点。公开 EditorGuide／GuiDevelopment／Architecture 补齐入口、保存职责、命令示例及日志范围。

## 验证

原始证据继续保留在 artifacts/status-bar/v1/（区分 build-clean.log、editor-clean.log 与首轮日志）。测试使用 git archive HEAD 导出的独立 Sandbox，用户工程不参与保存操作。

- `cmake --build build/cmake-sandbox-meshes --config Debug --target RestArtEngine --clean-first --parallel 3`：退出 0、无警告。
- 完整清理重建后启动不再崩溃，印证增量对象文件混合假设；CPU 重建后 13/13 通过（build-tests.log／cpu-final.log）。
- editor-clean.log：52 项 PASS 段落，包括原保存、浮窗和诊断回归，以及底栏 Enter 执行／Undo／Tab／历史／Delete/F/W 输入隔离的断言；最终在通过 select 参数验证后定位 Output Log 按钮失败。select 会延迟激活 Details 页签，自测导航定位抢在该请求处理前，下一帧 NavWindow 变为 Details；这是夹具同步缺口。保留原断言，v3 先稳定两帧再定位控件。
