# v4 — 按 ImGui 最小窗口尺寸预留底栏

状态：通过；前版 [v3](v3.md)。未提交／推送。

## 分析与修改

高缩放时 WindowMinSize 高于按一行控件加 padding 计算的高度。底栏实际 Begin 后被 ImGui 放大，而 DockSpace 仍按较小高度预留。将 statusBarHeight 统一为 max(行高 + 8, WindowMinSize.y)，同时用于底栏和 DockSpace。现有布局断言和截图保留。
