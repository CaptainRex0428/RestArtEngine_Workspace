状态：首轮未通过，后续见 [v2](v2.md)。基线：引擎 f6e3295 与已有保存职责拆分／浮动窗口未提交修改；Windows Debug。

## 分析与设计

用户提供 UE 底栏参考图并要求接入现有功能与命令行。已阅读 [Epic 官方界面说明](https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-editor-interface)：底栏包含内容入口、日志／命令、Trace 与保存状态。本轮遵循其工具组织方式，使用 RAEngine 自身 Black／Dark Blue 主题，不添加尚无实现的 Revision Control、Derived Data 等入口。

底栏预留独立高度，DockSpace 和场景视口重新排版。左侧 Content 焦点入口／Output Log，中部 Cmd 输入，右侧 Tools（诊断、Frame Inspector、GC、项目设置、Trace）与全局保存状态。窄窗口把左侧入口收进 Tools。Content 聚焦已有面板，不宣称实现 UE 临时抽屉。日志为可停靠／外移窗口，记录本会话编辑器状态和命令结果，不捕获系统 stdout 或全量渲染日志。

## 修改与验证

EditorConsole 为独立无 UI 模型，注册命令／解析参数／help／clear／补全／历史和有界输出，错误独立反馈，不执行系统 shell。GUI 命令复用既有命令注册／撤销，Save 特殊返回实际成功／失败，保留 scene-only 与 asset-only 语义。输入焦点在视口处理键盘前确定。

主 agent 负责 GUI、布局、构建、编辑器测试及日志；子 agent 负责模型和 CPU 测试。待构建／运行 CPU 和完整编辑器测试，原始证据在 artifacts/status-bar/v1/。保留其他任务所有改动。
