# v1 — 资产重新导入与删除

状态：完成，常用 Debug 程序已更新。基线：HEAD `f6e3295` 的共享工作区，已有大网格持久化／GUI 等未提交修改；不撤销或混入提交。

## 分析

导入器已保存 sourcePath，但仅支持生成新 GUID 的导入；缺少保留身份的原子替换。Content 的 Delete 菜单对所有 loaded mesh/material 禁用，原路径只删文件会导致 Save All 重新生成。Undo 闭包会恢复旧引用，当前没有可查询的资产依赖元数据。

## 设计与修改

右键 Reimport 使用原路径，Reimport from... 单选新源；共享现有格式和导入选项。解析和临时写入全部成功后替换原文件和内存，保留 GUID/name/path，失败不变。选择新路径成功后保存新来源。

Delete... 确认后删除项目文件和内存资产；保护当前与保存场景引用、Engine、活动／启动场景和 Shader；检查失败拒绝。删除资产不删除源文件。删除 mesh/material 成功清理编辑历史，确认框解释不可撤销及历史清理；失败／取消保持历史。
