# v1 — Slot 默认材质声明与居中环绕预览

状态：通过
基线：`8bbd1c9`；实现提交 `79bf6d0` 已推送。

## 用户需求

1. 打开网格的 Asset Details 窗口时，可以声明材质 Slot。
2. 网格预览可以旋转查看，但永远以物体为中心。

## 实现

### Slot 材质

- 网格详情在 `Material slots: N` 下逐行显示 Slot 名称与当前默认材质，并提供下拉：
  - `Actor fallback`（`defaultMaterialId=0`，沿用 Actor 材质）；
  - 工程／引擎材质列表（按 AssetId 写入 `MeshMaterialSlot::defaultMaterialId`）。
- 旧式无 Slot 网格显示合成行 `0: Default (whole mesh)`；首次选择材质时创建一个 `Default` Slot（单一 Slot 无需 section，保持兼容）。
- `Save slot materials` 按钮调用 `makeMeshAssetFile` + `attachThumbnail` + `writeAssetFile`，写回该网格 `.rasset` 并保留缩略图；保存后 `refreshContent()` 重载注册表。
- 保存后重新 `findMesh`，避免 registry／AssetLibrary 重建后继续使用旧 `entry`／`mesh` 指针。
- 引擎内容（`engine://`）只读：仍显示 Slot 与分配，但下拉和保存禁用。
- 保存会重写整个容器；398 MB 的 Audi 网格可能停顿，UI 明确提示。

### 居中环绕预览

- `SceneRenderer::renderScenePreview` 增加 `yaw/pitch/zoom` 参数；相机 `cameraTarget` 始终是可见网格包围盒中心，距离按 `radius*2.6*zoom` 计算。
- Asset Details 预览区域支持拖拽环绕（鼠标横向改 yaw、纵向改 pitch，clamp ±1.3）、滚轮缩放（0.4–3.0）、双击复位；悬停显示操作提示。
- 预览缓存键包含 yaw/pitch/zoom；拖动时即时重渲染 190×190 预览。
- 详情窗口默认尺寸改为 700×720（网格），给多 Slot／UV 信息足够空间，并保留手动缩放。

## 边界

- 不支持在详情窗口新增／删除 Slot 或重划分三角形区间；这需要导入器或几何编辑。
- 不支持从 Content 拖材质到某一行（当前用下拉选择）；Actor 级 Slot 覆盖仍在 Details 面板。
- 保存是整容器重写，不是增量 patch；大网格保存期间 UI 会阻塞。
- 预览的旋转不写入网格或场景，仅会话内状态；关闭后重开回到默认视角。
