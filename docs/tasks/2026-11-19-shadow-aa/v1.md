# v1 — 4096 阴影图与 4×4 PCF

状态：通过
基线：`b142549`；实现提交 `eaf4193`，文档提交 `8bbd1c9`，均已推送。

## 分析

用户截图显示阴影边界有明显阶梯。默认 `ShadowMap` 是 2×2 PCF（4 次双线性比较），阴影图 2048²，方向光正交投影 30 世界单位；每 texel 约 1.46 cm，近距观察时阶梯明显。FXAA/TAA 只能平滑最终颜色，无法恢复阴影图缺失的覆盖率；PCSS 虽软但更贵且不是默认。

## 修改

- 阴影图 `shadowMapSize` 2048 → **4096**，单 texel 世界覆盖减半；两层深度数组约 128 MiB。
- 新增 `ShadowMethod::ShadowMapPCF16`（`shadowParameters.w=5`）：4×4 固定偏移网格，16 次硬件双线性比较，等效约 8×8 texel 覆盖；固定偏移避免静态阴影的时域抖动。
- 默认 `SceneSettings::shadowMethod` 改为 `ShadowMapPCF16`；旧 2×2、硬比较、3×3、PCSS、CSM、GTAO、Contact、Analytic、Disabled 全部保留。
- `RenderFeatures` 增加对应条目；Scene 面板下拉加入 “Shadow map (4x4 PCF soft)”（10 项，clamp 0..9）。
- `EditorSmoke` 增加 `deferred_shadows_pcf16` 捕获与“与 Disabled 不同”的断言。

## 结论与边界

默认阴影边缘明显改善；4×4 PCF 每像素 16 次比较 + 4096² 阴影图是明确的质量/开销取舍，低端设备仍可选 2×2/3×3/硬比较。未实现：自适应分辨率、级联按距离动态分辨率、时域阴影降噪、PCSS 降噪和局部灯独立阴影图。
