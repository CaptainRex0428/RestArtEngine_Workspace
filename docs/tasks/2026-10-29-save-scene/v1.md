状态：CPU 和性能验证通过，编辑器自测未完整通过；后续见 [v2](v2.md)。基线：引擎 f6e3295，Windows Debug；保留用户 Sandbox 未提交修改。首次尝试。

## 分析

用户点击 Save Scene 后窗口无响应；截图仅约 1.9 万场景三角形，而 Content 仍有约 326 MB、3,877,264 三角形的 R8。

源码确认 saveScene 无条件 saveMeshes；所有 Imported 项目网格重复二进制打包、缩略图光栅化、复制和同步写盘。makeMeshAssetFile 为每顶点每轴查询转换 JSON 包围盒；World::save 又扫描包括未引用网格在内的全部几何。saveAll 重复保存材质。尚需受控计时证明成本，未据截图断言死锁或 GPU 错误。

## 修改与验证

- AssetLibrary：已加载／发布的现代容器记录几何版本、元数据、目标路径、大小／mtime；匹配则跳过序列化。失败不建立 clean，移动／删除／变更／旧格式迁移会重写。
- World：仅写 Actor 引用的资产清单；几何按引用与 geometryKey 校验，仍检查重复 ID、归属、Actor 引用和变换。
- AssetFile：用版本化 localBounds 生成 manifest，去除每坐标 JSON 操作。
- SceneEditor：Save All 去掉重复材质保存，Save As 与 Save Scene 都先保存资产后场景，成功后清除已保存标记。
- Debug 构建通过且无警告，最终 CTest 11/11 通过，新增 MeshPersistence 65 checks、ScenePersistence 45 checks。首轮旧 EngineContent 断言仍期待未引用项目材质进入清单，改为符合新契约后通过。六个内置网格重建与分发文件字节一致。
- 隔离 R8 四次旧版保存分别 88849.5、78759.7、78134、80816.9 ms，全部重写。新版未引用首次／重复 6.2553／5.5699 ms；引用首次／重复 217.757／5.6893 ms，全部不重写。Debug 同一模型、副本和相同 probe 源，计时仅 saveMaterials/saveMeshes/World::save，不含启动、UI 或 GPU 缩略图；第一次旧样本与构建存在 CPU 并发，不据此宣传通用倍数。
- 完整 editor-self-test 的既有渲染、拖放、材质、诊断、导入与新增 Save As 成功／失败、Save Scene 检查通过，最后 Save All 控件定位失败：测试忘记 ImGui BeginMenuBar 的 `##MenuBar` ID scope，并非保存逻辑报错。保留原始 editor.log 与截图，v2 修正测试再验收。
- 原始证据 `artifacts/save-scene/v1/`：build*.log、cpu.log/cpu-final.log、before-timing.log/after-timing.log、probe 源码、generated-comparison.json、editor.log/editor/。

## 结论与经验

实测证实全量资产重写是本次主要阻塞来源，增量路径已消除此重复成本；编辑器完整验收继续由后续版本完成。首次／实际修改的大网格仍同步保存。size+mtime 不是内容哈希，不能保证发现保持二者不变的外部编辑。既有资产容器写盘仍非原子替换；场景 JSON 原本已用临时文件替换，二者不构成整体事务。不把失败可重试宣称为所有磁盘文件绝对无损。
