# v2 — UI 生命周期、真实场景与最小化提交

状态：原生 D3D12 专项通过，旧路径和独立 RHI 回归收尾中。
前一版：[v1](v1.md)。基线仍为 14a6b0d 加未提交 M1/M2/M3。

## 分析

DX12 ImGui Shutdown 自己先清理主视口数据，再销毁平台窗口；不能沿用 DX11 先统一 DestroyPlatformWindows 的顺序。vendored DX12 实现为每个副窗口建立独立 command queue，主队列提交先后顺序不能替代跨队列完成。最小化主窗口不 present，但副窗口仍消费本帧 preview；若只在 renderMain=true 时转换纹理状态或只在 present 时清理 UI 借用，会出现无效状态或持续保留。

## 修改与验证

- UI 的所有 native12 帧都 prepareUi→主队列 submitAndWait→各副窗口 Render/Swap→finishUiFrame。副窗口 SwapBuffers 等自身 fence；最后再退役 UI 图像与描述符，不依赖主 present。
- scene/preview 替换保留旧代直到本帧全部 UI 完成；每次常量 write 创建独立上传版本，记录 Draw 的版本保留到 fence。窗口 resize 拒绝外部仍持有的 swapchain wrapper，避免重新包装旧 surface 导致状态失配。
- 公共 RHI Shader 编号替代原生 Shader 指针选择；原生12对未移植的软件射线、DXR/GI、DOF/Outline、Inspector 资源捕获与 GPU 查询明确报告能力缺口，保留原请求。

实际结果：

1. Debug 构建通过；既有 CTest 24/24。首次测试预设名称错误后改用 `ctest --test-dir build/cmake-vs2022 -C Debug --output-on-failure`，没有把未运行命令当作通过。
2. 原生12禁回退 14 帧成功，实际 RTX 5060、D3D11 device=no、D3D12 debug enabled/errors0；保存14张截图。证据 artifacts/native12-start-v2.log。
3. `--native-d3d12-self-test`：Forward/Deferred 同场景 RGB 平均误差 0.00896（0..255），深度、PCF/PCSS/CSM2/GTAO/Contact 均有实际像素变化；材质、相机、独立 slot、超 swapchain 离屏尺寸、resize、GC、成功热编译/失败保留均通过。
4. 真实独立工具 HWND/renderer data 创建、同帧借用旧纹理后替换、主窗最小化两次 endFrame(false) 与材质绿→蓝回读变化 11537 像素，恢复/关闭副窗通过，debug errors0。主窗截图已查看；副窗口本身没有 GUI 像素回读或截图视觉验收，不混同为完整 GUI 验收。

专项证据：artifacts/native12-features-v1（场景六组）、native12-features-v2（新增 UI），含 JSON 和 BMP。启动六案例矩阵成功、严格11/Auto图像逐字节一致，证据 artifacts/native12-startup-matrix.log；最终独立 RHI 与旧 DXR/Editor 回归见后续版本。
