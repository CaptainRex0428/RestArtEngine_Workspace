# 检查实时 GI 的贡献与成本

- 用同一接收面、两种供光表面颜色，比较间接光 RGB。掩模同时检查法线和金属度，记录有效像素数，避免把供光物体自身或没有漫反射的金属面算作接收面。
- 核对 GI 关闭、零增益 Lit 与零增益 GI indirect；分开检查首帧和已有历史帧。诊断 EV 只在读图时使用，报告注明是否放大。
- SH 基系数有正负号。距场可见性需要在实际接收 Pass 绑定并按方向读取。检查同一帧原始图像和最终输出，验证层零错误只能说明 API 调用合法。
- 查预算时数真实的光线、步数及更新区域；软件光线以一次暂存供所有 SH 系数复用。成本报告记录 GPU/后端、相机、分辨率、异步采样帧数和队列范围。原生 DXR 独立 command list 的工作不在随后的 RHI 光栅时间戳区间里，整帧 readback 边界之间的均摊墙钟时间还包含 CPU、提交与同步。

- 探针光斑需要分别测平面和曲面。对同曝光平面图取 tile 均值、扣除二次渐变，再测归一化局部残差与不同方向的二阶差分。用同一曲面内部的近黑像素占比检查 SH 截断。另取相邻帧、较长静置后的一帧，以及少量有遮挡的离线参考点，区分采样闪烁、固定格纹和真实的大尺度色变。记录薄壁或灯背漏光等参考失配。
