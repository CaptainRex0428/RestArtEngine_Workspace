# 检查实时 GI 的贡献与成本

- 用同一接收面、两种供光表面颜色，比较间接光 RGB。掩模同时检查法线和金属度，记录有效像素数，避免把供光物体自身或没有漫反射的金属面算作接收面。
- 核对 GI 关闭、零增益 Lit 与零增益 GI indirect；分开检查首帧和已有历史帧。诊断 EV 只在读图时使用，报告注明是否放大。
- SH 基系数有正负号。距场可见性需要在实际接收 Pass 绑定并按方向读取。检查同一帧原始图像和最终输出，验证层零错误只能说明 API 调用合法。
- 查预算时数真实的光线、步数及更新区域；软件光线以一次暂存供所有 SH 系数复用。成本报告记录 GPU/后端、相机、分辨率、异步采样帧数和队列范围。原生 DXR 独立 command list 的工作不在随后的 RHI 光栅时间戳区间里，整帧 readback 边界之间的均摊墙钟时间还包含 CPU、提交与同步。

- 探针光斑需要分别测平面和曲面。对同曝光平面图取 tile 均值、扣除二次渐变，再测归一化局部残差与不同方向的二阶差分。用同一曲面内部的近黑像素占比检查 SH 截断。另取相邻帧、较长静置后的一帧，以及少量有遮挡的离线参考点，区分采样闪烁、固定格纹和真实的大尺度色变。记录薄壁或灯背漏光等参考失配。

对应的夹具、掩模选择失败记录和修正后的 GPU 读回结果见[本次 GI 验收](../tasks/2026-11-23-gi-review/README.md)。

频闪测试连续读回同曝光 Lit 帧，明确实际的漫反射与镜面来源、AA、迟滞和强度。先固定预热帧数，再同时测 8×8 色块的时间极差 P95、相邻帧像素差 P95 和相对 GI-off 的亮度。暗图也可能看起来稳定，需要保留贡献门槛；早期收敛和稳态的结果分别记录。

动态响应另测灯光阶跃，记录编辑帧和达到新稳态的帧数。移动遮挡物或镜头时，另看遮挡边缘的残影及静止后的再收敛。硬件反射的空间颗粒用固定金属接收面的局部高频残差衡量，GPU dispatch 与光栅合成各自计时。只抑制逐帧闪烁时，稳定方向仍可能产生固定重影或高亮圆斑，需要看粗糙墙和金属球。实例见[录屏修复对照](../tasks/2026-11-23-gi-review/v5.md)。

检验迟滞滑块要覆盖两个方向。在预热后从 1 向下拖动，用相邻帧比较发现不必要的缓存重置。再把迟滞保持在 0 后调回 1，以切换前的稳定图作参考，检查后续 16 帧能否消退单帧噪声。历史权重跟随缓存实际保留的样本数，采样方向序号独立递增。

同一画面同时用 SSGI 和 DXR 时，定位固定光斑可在最后合成处分别保留漫反射或镜面，保持原来的追踪路径与回退设置。再屏蔽单个命中物体的供光，保留命中计数与遮挡，比较不同追踪半径和步数下的边界。见[天花板弧带对照](../tasks/2026-11-23-gi-review/v6.md)。

固定弧边应量化空间落差，同时保留仅屏蔽供光后的能量对照。标准 Cornell 自测的同曝光间接图还可以加入左球上方亮度和两侧墙的颜色门槛，防止压暗或去色让空间平滑检查误过。见[弧带修复验证](../tasks/2026-11-23-gi-review/v7.md)。

验证金属倒影时，只改供光墙颜色，在内缩的纯金属掩模中测红、蓝两通道的方向变化。再保持墙色不变，仅关探针，分别测金属与非金属地板，以分辨探针颜色泄漏和真实镜面。SSR 同时保留默认距离的 Lit 图，以及射程确实够到供光墙的换色实验。探针与反射共用 DXR 提交时分别核对 0／1／2 次 dispatch，并按实际 dispatch 标记去重记录 GPU 时间。[金属倒影验证](../tasks/2026-11-23-gi-review/v8.md)
