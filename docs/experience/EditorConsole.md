# 编辑器底栏与命令输入

## 场景与原因

全局工具栏直接覆盖主窗口底部会遮挡 Dock 面板；命令框晚于场景视口处理焦点时，F/W/Delete 等按键可能先触发场景动作。另建一套命令回调容易绕过撤销、可用性和保存失败状态。

## 处理原则

- 固定底栏只属于主 viewport，实际高度从 DockSpace 可用空间中扣除。尺寸使用当前字体／控件高度，并包含 ImGui WindowMinSize 下限；否则高缩放时实际窗口大于预留高度。窗口变窄时将次要入口收进 Tools，保留命令和保存状态。
- 控制台解析与 GUI 分离，注册既有编辑器命令，仍走原 enable predicate／事务；保存操作返回实际成功或错误，不能将“已分派”当成“保存成功”。明确该入口执行引擎命令，新增脚本语言需另行设计。
- 在视口处理键盘前提交输入框和日志窗口焦点；既保护文本编辑，也保护日志筛选／按钮上下文。
- 有界保存历史与日志；历史 Down 在未浏览时不改输入，浏览结束恢复草稿；语法错误不执行回调。限定参数生命周期，保持注册回调的状态与调用期间寿命。

## 防回归与边界

用真实 InputText 的 Enter、Tab、Up/Down 和 Delete/F/W 验证行为，用 Actor 数量／Undo cursor 证明操作沿原事务。检查主 workspace 与 footer 矩形不相交，以及两主题、宽窄窗口和字体／控件同时缩放后的实际截图。测试前后保护用户文件哈希，Save All 仅在临时项目执行。

沿用 GUI 技能的延迟页签原则：Actor select 会排队激活 Details，测试导航定位其他控件前先提交稳定帧。样式循环先恢复基线，再应用目标主题，最后缩放，避免把截图标成蓝色主题但颜色实际被旧样式覆盖。

本实现 Output Log 只记录编辑器状态和命令结果，不等于全量引擎日志管道；Content 入口聚焦原面板，不等于 UE 临时抽屉。源码类型布局变化后若增量产物在旧类型析构处崩溃，先使用匹配 PDB 定位并做干净重建验证，不能仅凭崩溃猜测生产代码根因。
