# 路径追踪示例、发光面与启动视角

## 场景与原因

用户参考图里的白色顶灯既照亮房间，又出现在镜面球中。只设置白色 albedo、黑背景或增加反弹数不能实现这种光传输；先核对材质／灯光能力，区分相机背景和环境能量。示例还需保存初始视角，否则启动后的默认轨道角度无法复现构图。

## 处理原则

- 独立示例使用 Engine 的稳定网格 GUID、项目材质和场景配置，不修改用户 Sandbox，也不复制旧示例中损坏或过时的资产。离线生成器用正式资产 API 写出缩略图和容器并重载验证，默认拒绝覆盖非空目录。
- 相机书签是显式场景数据；导航不自动标脏。旧文件缺少 camera/lighting 时保持原行为，解析使用 staged World，非法数据与保存失败保留原状态。
- 单面矩形解析光源按射线和场景最近距离确定可见性，遮挡只检查灯前的有限线段。面积与 BSDF 直达光估计器要有互补 MIS，普通续射命中同灯不能再重复计光。
- 直接光与间接首段贡献开关分开，保持 maxBounces 边界；禁用新灯不额外消耗原采样序列。Shader 常量、reflection offset、上传槽与累积历史 key 必须一起更新。
- 如果同时存在另一套 LightActor 开发，明确来源优先级，不能把场景旧矩形与新灯列表自动叠加；当前示例没有 LightActor。并发任务须用固定快照验收，保留其他任务改动。

## 防回归

GPU 分别测发光面正背面、前景挡灯、漫反射接收面、灯后几何不遮挡、灯前遮挡、阴影开关、参数改动重置历史和禁用恢复。镜面用接收球实际 Albedo mask 内的高亮验证，不能以全图差异代替反射——球仅挡住灯也能导致全图变化。

有限帧示例输出必须报告实际 effective mode、累计样本和 DXR dispatch；照片感或噪点不能作为硬件启用证据。检查真实样例画面及编辑器启动，源码冻结后比较哈希，不把另一路未完成测试当成本任务完整验收。用户正在运行的程序不可为了替换产物而关闭，交付独立验证产物及明确启动方式。

## 边界与来源

艺术间接漫反射强度必须作用于首接收表面的漫反射 BRDF，并让采样概率与混合 PDF 匹配；直接光估计和后续顶点使用原始 BRDF。不能把完整path throughput无条件乘倍数（会改变首段镜面），也不能每跳相乘（会指数放大）。有效倍率进入历史键，非有限值不能污染shader/history equality；保存接口严格拒绝非法值，运行时调用边界保留防御。验证需包含0与bool-off一致、1恢复、3倍近似线性、纯金属首接收面（包括镜中的漫反射墙）不变，以及实际滑条拖动／保存。来源：[艺术强度v2](../tasks/2026-10-30-cornell-bleeding/v2.md)。

颜色互染偏弱时，先检查实际材质反射率、主直射比例与GI贡献，再用相同相机／曝光／预算比较关闭间接、侧墙中性和改变反射率的隔离图像。固定接收面ROI的显示RGB可证明可见颜色响应，不能当作线性辐射度或物理参考验证。增加目标样本主要降低噪声，不能作为增加反弹能量的旋钮；没有漏算证据时，应区分场景调整和明确标识的艺术增益，不默默修改输运公式或用户资产。来源：[互染诊断v1](../tasks/2026-10-30-cornell-bleeding/v1.md)。

来源：[Cornell Box v1](../tasks/2026-10-29-cornell-box/v1.md)。本次 Windows/DX11＋DXR progressive；单解析面不是通用发光材质或透明折射。默认1024样本不保证无噪点，不将不同视口宽高比下构图外推为像素一致。

隔离GPU自测跨盘复制工程时，相对engineRoot可能无法保留，旧恢复逻辑会退回本机注册表并加载另一工作树Shader；测试副本应显式固定候选engineRoot，不能仅依靠命令行hint。共享HEAD或暂存区发生并发变化时，不覆盖真实索引；可用独立索引和分支固定已验收的候选，明确尚未合入当前分支及后续集成验证。来源：[提交隔离v2](../tasks/2026-10-29-cornell-box/v2.md)。
