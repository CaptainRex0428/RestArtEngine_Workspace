# 启动加载的真实进度与呈现边界

## 场景与原因

加载条只有少量硬编码值时，Shader 编译、PSO、资产和索引变成不可观察的大段；若引擎管线完成即报告 100%，随后工程加载又从中间开始，百分比会倒退且错误表达完成。

## 做法

各加载器提供可选同步观察者，报告自身 0..1、阶段与当前项详情，调用方分配子范围。资源逐候选提供文件数及 UTF-8 文件名，保留 legacy 优先级、事务发布与失败语义；枚举只收集必要候选，不为进度重复读资产载荷。百分比代表工作预算，不能宣称剩余时间准确。

只有 UI 边界可以 clear / UI / present。Renderer 初始化内的回调不得重入 scene render、resize 或 teardown；窗口消息只记录状态，取消用独立信号展开，不能被资产读取的 std::exception 容错吞掉。观察者不得保留借用文字，也不能存入长生命周期 renderer 影响热编译。逐项日志与展示节流分开，同阶段可节流至约 30Hz，切阶段及时刷新，不添加人为延时。

保持加载 surface 覆盖工程初始化；完成实际编辑器首帧后再报告 Ready。只需 clear/UI 的 Project Manager 初始化 device 即可，不应重复创建场景 Shader/PSO。首个图形设备与 ImGui 可用前不声称能绘制 GPU 加载条。

## 验证

组合范围与单调性、逐项数量／UTF-8、损坏资产／Shader 失败不报 1、空目录、最终库保持；实际三个后端启动检查 Shader/PSO/工程/索引事件及提交画面。标签为百分比留出独立列，详情按 UTF-8 边界缩略并检查最小窗口。事件 presented 字段只在成功提交后记录，最小化／取消／失败不能伪报。

## 边界与来源

同步 loader 只能在安全步骤间反馈；一个 Shader 编译、一次大资产读取或设备创建内部仍可能等待。实时耗时预测、异步加载与线程取消是其他问题，不在此协议中伪装实现。来源：[2026-11-18 任务](../tasks/2026-11-18-loading-progress/v1.md)，实际运行证据在任务日志补齐后判定。
