# 实时 GI 方案清单与当前引擎边界

日期：2026-11-19
状态：讨论记录，未选择实现项

## 问题

用户问：目前只有 PathTracingGI，有没有实时 GI 方案，能否都列出来。

## 当前引擎实际支持

- `GlobalIlluminationMethod` 枚举只有 `Disabled`、`PathTracing` 两种算法。
- `GlobalIlluminationMode` 有 `Progressive`、`Realtime` 两种更新模式。
- 所以**已经有实时模式**：Path tracing + Realtime——每帧 1–16 spp，输出线性 HDR 间接光（可选 diffuse/specular），Forward/Deferred 在主表面直接光之后合成；5×5 边缘感知空间滤波，有界历史，无运动重投影/降噪器；相机或场景变化使历史失效。
- 这不是“第二种 GI 算法”；只是同一 PathTracing 算法的实时更新策略。当前没有 SSGI、DDGI、LPV、VXGI、ReSTIR 等。
- 相关但不是 GI 的功能：GTAO、Contact Shadow、硬件/解析光追阴影与反射、环境天空光；GI Disabled 时它们仍可工作，但不能算间接漫反射 GI。
- 后端：原生 D3D12 和混合模式都能执行 DXR realtime GI；严格 D3D11 只能跑光栅近似（目前没有 GI）。

## 可选实时 GI 方案

| 方案 | 基本做法 | 质量/特点 | 成本与依赖 | 主要边界 |
|---|---|---|---|---|
| PathTracing + 时域降噪（SVGF/NRD/ReBLUR 类） | 1–2 spp 光线追踪，运动向量重投影、方差估计、à-trous/时域滤波 | 最接近真实 GI，可同时给 diffuse/specular；与现有 DXR 管线最接近 | DXR 1.1；需要运动向量和更完整的降噪/历史管理；GPU 成本中高 | 动态几何/透明/毛发难；时域拖影；调试复杂 |
| ReSTIR GI / ReSTIR DI | 时空蓄水池重采样复用间接/直接光样本 | 少量 spp 获得低噪点，适合多光源/动态场景 | DXR；蓄水池、时空复用、偏移/可见性校验；实现复杂 | 时空相关性导致闪烁/拖影，需偏差控制 |
| SSGI（屏幕空间 GI） | 在深度/法线/颜色缓冲上射线步进，取屏幕内间接光 | 便宜、无需 DXR，能补接触处颜色溢出 | 光栅后端通用；深度/法线厚度、降噪、时域累积 | 屏幕外信息缺失、背面/遮挡错误、边缘泄漏 |
| DDGI / RTXGI（动态漫反射探针） | 世界空间探针网格；八面体 irradiance/depth；每帧更新部分探针 | 动态场景/昼夜稳定，光栅着色可直接采样；可与 SSGI 互补 | DXR 更新或 cubemap 渲染；探针存储/更新调度；大世界流式 | 探针泄漏、分辨率有限、薄墙需深度探针；镜面反射不适用 |
| LPV（Light Propagation Volumes） | 级联网格注入直接光并传播/传播多次 | 便宜、动态、实现较早 | 光栅/计算；级联网格和传播核 | 漏光、范围有限、质量偏软，现代项目少用 |
| VXGI（体素锥追踪） | 场景体素化，锥体追踪近似间接光 | 动态、方向性比 LPV 好 | 体素化/内存/过滤；更新和清理由场景变化驱动 | 内存高、漏光/闪烁、细几何丢失；实现重 |
| 世界空间辐照度/辐射度缓存 | 点云或哈希网格缓存间接光，增量更新 | 与 path tracing 互补，可降低采样需求 | 缓存查询、更新预算、去重 | 缓存漂移、动态场景失效、实现复杂 |
| 预计算实时 GI（Enlighten/SplineGI 类） | 预计算可见性/传递，运行时动态光照 | 质量稳定、开销可预测 | 离线预计算、光照探针/集群、动态物体接入 | 几何/灯光动态受限，工具链成本高 |
| 烘焙 lightmap + 光照探针 | 静态光烘焙，动态物体采样探针 | 最便宜稳定 | 离线烘焙、UV/探针工具 | 不是真正实时；动态场景/可破坏几何受限 |
| RTAO + 屏幕空间间接光近似 | 光追 AO 乘环境光，再少量屏幕空间反弹 | 改动小、提升接触阴影和基础间接感 | DXR 或屏幕空间；不采样完整光传输 | 不是完整 GI，无彩色溢出/多次反弹 |
| 混合方案（SSGI+DDGI / RTGI+SSGI） | 近场屏幕空间细节 + 远场探针/光追 | 生产中常见，质量与成本折中 | 两套管线、切换/融合逻辑 | 实现与验证成本最高，但最可控 |

## 与本引擎的匹配建议

1. **短期最高收益**：在现有 DXR PathTracing Realtime 上补运动向量和时域降噪（SVGF 类）。现有代码已有法线/位置/albedo 引导、历史、5×5 空间滤波；缺的是运动向量、重投影和方差/À-trous。
2. **光栅 fallback**：SSGI + 时域累积，给严格 D3D11/无 DXR 设备一个实时 GI 近似；与现有 Deferred G-buffer 天然匹配。
3. **大型动态场景**：DDGI 探针 + 光栅着色，DXR 只更新部分探针；可与 SSGI 混合补细节。
4. **不推荐先做**：VXGI/LPV 质量/维护成本不划算；预计算实时 GI 工具链成本高；ReSTIR 放在已有实时 GI 稳定后。
