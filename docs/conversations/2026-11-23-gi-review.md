# SSGI 与 DDGI 的显示、计算与质量分级

用户要求评审已有两种 GI 并实际完善。以引擎 `8f7dd2c` 的可运行版本为起点。保留 Deferred 的两种方法，SSGI 的可选 DXR 反射只负责镜面；DDGI 使用屏幕空间或 DXR 追踪探针，向接收表面提供低频漫反射。质量档绑定主要 GPU 预算，各方法独立保存 Custom。针对画面不明确的问题，用上一帧实际算法、仅间接光、临时显示曝光和探针辐照度定位原因。
