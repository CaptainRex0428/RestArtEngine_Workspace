# 屏幕 GI 的预算与屏外互染（2026-11-27）

用户确认继续完成上一轮渲染评审的三个方向。引擎基线为 `380a447`。本轮实现与固定夹具数据见 [v11](../tasks/2026-11-23-gi-review/v11.md)。

## 实现决策

- 相机、灯光和几何变动时，屏幕空间 DDGI 优先重算整张探针图。连续稳定后轮换保底更新，再用辐射变化量分配额外工作。实际 GPU 时间和理论射线上限分别记录。
- SSGI 在当前帧估计方差，用历史深度的重投影覆盖率和运动量控制重建范围。移动灰球和转动相机分开测，墙角保留的亮度梯度与同曝光基线对照。
- 软件世界空间 GI 首版以静态网格体素化并缓存表面光照，供光墙退出视口后仍能参与一次漫反射。质量档控制探针、方向数与体素密度。用薄隔墙、移灯、粗糙灰球和中性地板同时验证颜色传递。

## 范围

屏幕追踪、世界空间探针和镜面反射保留独立配置。世界空间体素以 Windows 的 Deferred 路径验收。大世界级联、千万面动态重建及其他平台需要各自的预算和实测。后续混合追踪和低采样路径追踪在[路线待办](../DevelopmentStatus.md)单独跟踪。
